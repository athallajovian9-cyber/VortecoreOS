How to Run & Install VortecoreOS

You can run VortecoreOS directly on your PC using the zero-setup VM runner, inside QEMU / VirtualBox, or written to a raw bootable USB.

Method 0: Direct Graphical Desktop Environment (Windows Instant GUI)

Launch the full 1024x768 32-bit TrueColor desktop compositor with movable windows, taskbar, Terminal, and RTOS monitor:

1. Extract VortecoreOS-Desktop-x64-v1.2.0.zip
2. Double-click "START_DESKTOP_GUI.bat"
3. Enjoy the interactive multi-window desktop interface!

Method 1: Zero-Setup Instant Runner (Console Shell)

VortecoreOS includes an interactive virtual machine runner that boots the raw 64-bit MBR image directly on your screen without needing any third-party emulators installed.

1. Download VortecoreOS-Rust-v1.0.0.zip from GitHub Releases
2. Extract the ZIP folder
3. Double-click "RUN_VORTECORE_VM.bat"
4. The 64-bit interactive shell REPL will boot instantly!

Method 2: Boot via QEMU (Linux / Mac / Windows)

If you have QEMU installed, you can boot the compiled 512-byte raw disk image (boot.img) directly:

qemu-system-x86_64 -drive format=raw,file=boot.img

Method 3: Flash to Real Hardware (Bootable USB Drive)

To boot on a real physical x86_64 computer with Legacy BIOS / CSM enabled:

# On Linux / Mac:
sudo dd if=boot.img of=/dev/sdX bs=512 count=1 status=progress && sync

# On Windows:
Use Rufus or Etcher to write boot.img directly in DD image mode to your USB drive.

Interactive Commands to Try Once Booted

Once you are in the vortecore-rust# shell, run these commands:

help        - Show all available commands
